# RetroCast for iPhone – Local on the 8s

A 1990s cable-weather style local forecast built for iPhone in portrait. It stays upright when you turn the phone.

## Install (GitHub Pages)
1. Create a new GitHub repo (e.g. `retrocast-iphone`) → **Add file → Upload files** → drag in everything from this folder (keep the `css`, `js`, `icons`, `fonts` folders).
2. **Settings → Pages** → Source: *Deploy from a branch* → `main` / `(root)` → Save.
3. On your iPhone, open the Pages link in **Safari** → **Share** → **Add to Home Screen**. Launch it from the Home Screen icon.

## Using it
- **Swipe** left/right to change pages. **Tap** to show the controls (back, pause, next, music, location, settings).
- Music starts after your first tap (iOS requires a tap before playing sound).
- Current conditions and alerts refresh every 30 seconds; the full forecast every 15 minutes.

## Data (free, no API keys)
Open-Meteo (worldwide forecasts) and NOAA / National Weather Service (US observations, forecast text and severe alerts).

A fan tribute to 1990s cable weather. Not affiliated with The Weather Channel.
