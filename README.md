# RetroCast for iPhone – Local on the 8s

A 1990s cable-weather style local forecast built for iPhone in portrait. It stays upright when you turn the phone.

## Install (GitHub Pages)
1. Upload everything from this folder to your repo (keep the `css`, `js`, `icons`, `fonts` folders).
2. **Settings → Pages** → `main` / `(root)`.
3. On iPhone, open the link in **Safari** → **Share** → **Add to Home Screen**.

## Using it
Swipe left/right to change pages. Tap for controls. Music starts after your first tap.
Current conditions and alerts refresh every 30 seconds; the full forecast every 15 minutes.

Data: Open-Meteo and NOAA / National Weather Service. A fan tribute, not affiliated with The Weather Channel.
